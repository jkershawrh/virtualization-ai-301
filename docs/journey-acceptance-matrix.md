# Journey acceptance matrix

| Journey | Learner action | Pass condition | Not sufficient |
|---|---|---|---|
| Presentation | Run three conditions | State correlation checks result and authority visible at target viewports | Diagram or cached result |
| Guided demo | Inspect and challenge observations | Explain REFUSE versus ABSTAIN | Component names |
| Showroom lab | Declare observe compare break review reclaim | Tests manifests records and before/after inventory pass | One successful request |
| Live qualification | Execute on approved target | Launchpad accepts VM Service policy VMI/node model metrics restart and cleanup | Factory rehearsal |

Human acceptance is separate from adapter output and grants no certification.
