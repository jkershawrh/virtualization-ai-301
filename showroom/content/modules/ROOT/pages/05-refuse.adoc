= 5. Make the system refuse and abstain

== Show

A governed system is defined as much by what it will not claim as by what it
can produce. You will run three faults through the same API.

== Do

First, change the observed service account. Identity must fail and every later
check must remain `NOT_RUN`.

[source,bash,role="execute"]
----
jq '.observed.identity.service_account = "unexpected-caller"' \
  "$LAB_DIR/request.json" >"$LAB_DIR/identity-fault.json"
curl -fsS -X POST "$ADAPTER_URL/api/v1/modernize" \
  -H 'Content-Type: application/json' --data-binary @"$LAB_DIR/identity-fault.json" \
  | tee "$LAB_DIR/identity-response.json" | jq .
jq -e '
  .outcome == "REFUSE" and
  (.reason_codes | index("IDENTITY_MISMATCH")) != null and
  .checks.identity == "FAIL" and .checks.network == "NOT_RUN" and
  .ai_participated == false and (has("advisory") | not)
' "$LAB_DIR/identity-response.json"
----

Next, remove the event evidence. Complete identity and network checks are not
enough when observability is incomplete.

[source,bash,role="execute"]
----
jq '.observed.observability.events_available = false' \
  "$LAB_DIR/request.json" >"$LAB_DIR/observability-fault.json"
curl -fsS -X POST "$ADAPTER_URL/api/v1/modernize" \
  -H 'Content-Type: application/json' --data-binary @"$LAB_DIR/observability-fault.json" \
  | tee "$LAB_DIR/observability-response.json" | jq .
jq -e '
  .outcome == "ABSTAIN" and
  (.reason_codes | index("OBSERVABILITY_INCOMPLETE")) != null and
  .checks.observability == "UNKNOWN" and .ai_participated == false
' "$LAB_DIR/observability-response.json"
----

Finally, simulate an approved model becoming unavailable only after the
controls pass.

[source,bash,role="execute"]
----
curl -fsS -X POST "$ADAPTER_URL/api/v1/modernize?condition=model-unavailable" \
  -H 'Content-Type: application/json' --data-binary @"$LAB_DIR/request.json" \
  | tee "$LAB_DIR/model-unavailable-response.json" | jq .
jq -e '
  .outcome == "ABSTAIN" and
  (.reason_codes | index("MODEL_UNAVAILABLE")) != null and
  .checks.model == "FAIL" and .source_state == "OFFLINE" and
  .ai_participated == false and (has("advisory") | not)
' "$LAB_DIR/model-unavailable-response.json"
----

== Prove

The three outcomes prove precedence: a bad identity refuses before network or
model work; missing telemetry abstains; and model failure fails closed after
the deterministic controls pass.
