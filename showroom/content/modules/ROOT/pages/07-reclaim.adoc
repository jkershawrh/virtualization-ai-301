= 7. Clean up and prove your boundary

== Learn

You created only local request and evidence files. The VM, adapter, Services,
NetworkPolicies, presentation, and Showroom are platform-owned lab resources.
The participant must not uninstall or delete them; Launchpad performs full
environment reclamation and independently proves zero residue.

== Show

Record the platform-owned resources that Launchpad will reclaim later.

[source,bash,role="execute"]
----
oc get vm,vmi,deploy,svc,networkpolicy \
  -l lab.redhat.com/candidate=virtualization-ai-301 -o name \
  | tee "$LAB_DIR/platform-owned.txt"
----

== Do

Stop the local tunnel and remove every learner-created file.

[source,bash,role="execute"]
----
if test -f "$LAB_DIR/port-forward.pid"; then
  kill "$(cat "$LAB_DIR/port-forward.pid")" 2>/dev/null || true
fi
rm -f "$LAB_DIR"/*.json "$LAB_DIR"/*.txt "$LAB_DIR"/*.log "$LAB_DIR"/*.pid
rmdir "$LAB_DIR"
----

== Prove

[source,bash,role="execute"]
----
test ! -e "$LAB_DIR"
oc auth can-i delete namespaces | grep -qx no
oc get vm "$VM_NAME" -o name
oc get deployment virtualization-ai-301-adapter -o name
----

The first check proves learner artifact cleanup. The final checks prove that
you did not destroy the platform-owned environment. Full namespace, Route,
RoleBinding, application, model-key, and identity cleanup is a separate
Launchpad reclamation gate.
